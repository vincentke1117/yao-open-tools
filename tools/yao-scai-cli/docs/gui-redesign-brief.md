# Scai GUI 重设计需求（磁盘空间清理顾问 · 桌面应用）

> 本文档是交给 UI 设计 agent 的完整需求，自包含、无上下文依赖。设计对象是已有可用功能的桌面应用界面重设计。

## 1. 背景与定位

Scai（Scan + AI）是一个 Windows 优先的磁盘空间清理顾问，便携单文件 exe，双击即用。核心流程已实现：选择目录 → 扫描 → 按风险分级展示清理建议 → 用户勾选 → 移到回收站（可恢复）。另有 AI 提示词复制与清理审计日志。

当前版本功能完整但界面是传统表单风（Python + tkinter）：顶部路径输入+按钮，中部一个数据表格，下方详情文本框+底部按钮排。问题：视觉陈旧、信息层级不清、空间大小缺乏直观感知、"勾选→删除"的操作重心弱。

产品铁律（设计必须遵守）：**只进回收站、永不永久删除；系统级"高风险"项只读锁定，不可勾选删除。**

## 2. 用户与场景

- 主用户：非技术~半技术 Windows 用户，"C 盘红了/空间不够"，想安全清理。
- 次用户：开发者（找 node_modules、构建产物、缓存）。
- 使用场景：一次性清理会话，3-10 分钟；扫描等待从几秒（小目录）到几分钟（全盘）。
- 用户心理：怕删错。**设计第一目标 = 信任感**：让用户随时明白"这是什么、为什么能删/不能删、删了能找回"。

## 3. 设计原则

1. 安全感优先于效率：删除永远可预览、可反悔（回收站）。
2. 风险即视觉：三级风险用一致的颜色 + 图标 + 文案贯穿全应用（列表、筛选、详情、确认框）。
3. 解释触手可及：任何条目一眼看到"为什么"（判断原因）和"怎么办"（建议动作）。
4. 大小可感知：空间数字要有冲击力（大字号主数字），欢迎图形化占比（treemap / 环形 / 堆叠条）。
5. 中文为主，术语克制：用"可清理 / 需确认 / 高风险"，不出现 safe/review/risky 英文标签。

## 4. 必须保留的功能（不能丢）

- 扫描：目录浏览/路径输入、"全盘安全扫描"入口（扫系统盘但跳过受管目录）、扫描进度与用时、记住上次目录。
- 结果浏览：文件+文件夹混合列表按大小排序；按风险筛选（全部/可清理/需确认/高风险）；"显示默认排除目录"开关；条目详情（大小/风险/分类/判断原因/建议动作/修改时间）。
- 选择与删除：多选勾选；已选汇总实时更新（件数+总大小，父子去重）；按目标自动勾选（输入如 20g，按"可清理优先"生成方案）；删除前确认清单；移到回收站；结果反馈（成功/失败+原因）；"打开位置"（资源管理器定位）。
- AI 提示词：生成含扫描摘要 JSON 的诊断提示词，一键复制给用户粘贴给任意 AI；应用本身不联网、不调用 AI。
- 审计日志：每次删除写入 `~/.scai/cleanup-log.jsonl`，界面可打开查看。
- 高风险项：只读展示（锁定态），文案说明"系统管理，请勿删除"。

## 5. 界面结构建议（信息层级，非最终布局）

单窗体优先（不建议复杂多页导航），按"扫描 → 浏览 → 决策"三段组织，具体布局欢迎重新构想：

1. 扫描区（可收起）：路径 + 开始扫描 + 全盘入口。扫描中变为进度态，展示已扫描目录数/文件数/用时。
2. 结果区（主舞台）：
   - 总览条：三个大数字——扫描根目录、可清理空间合计（safe）、需确认空间合计（review）。
   - 可视化（加分项，欢迎提案）：目录 treemap / 环形图 / 按风险堆叠条，点击与列表联动。
   - 数据列表：核心区，支持筛选与排序，行内直接勾选；文件夹与文件有视觉区分。
3. 决策区（常驻底部）：已选汇总（件数+大小实时更新）+ 唯一主按钮"移到回收站" + 次按钮组（按目标勾选 / AI 提示词 / 打开位置 / 打开日志）。
4. 详情面板：右侧滑出或底部可折叠，替代现在的固定 6 行文本。

## 6. 关键流程与状态设计

- 空态（首次打开）：欢迎语 + 一句话产品说明 + 选择目录引导；路径预填上次目录。
- 扫描中：进度 + 用时 + "正在做什么"的可感知反馈；全盘扫描提示耗时。
- 删除确认（模态）：清单预览（前 8 项 + 共 N 项 + 总大小）+ 明确文案"将移到回收站，可从回收站恢复"；所选含"需确认"项时给出琥珀色警示。
- 删除后：成功汇总（释放空间数）+ 建议重新扫描；失败项逐条给出原因。
- 错误态：路径不存在、权限失败等，用行内提示或 toast，不用阻断式弹窗。
- 可访问性：文字对比度达标；风险等级同时有图标+文字，不只靠颜色区分（照顾色弱）。

## 7. 视觉系统

- 三级风险色全应用统一：绿（可清理）/ 琥珀（需确认）/ 红（高风险·锁定）；请给出浅色与深色背景下的具体色值建议。
- 风格关键词：干净、专业、可信（工具感而非营销感）；信息密度参考 WinDirStat/TreeSize，友好引导参考 CleanMyMac/DaisyDisk。
- 明暗双主题为加分项。
- 中文排版：系统字体栈（Microsoft YaHei UI 等）；数字用等宽（tabular figures）对齐。
- 密度与尺寸：表格行高约 32-36px；窗口最小 960×640，支持最大化与高分屏缩放。

## 8. 技术与交付约束

- 运行形态：桌面单机、完全离线，最终打包为 Windows 便携单文件 exe（当前实现 Python + tkinter）。若设计超出 tkinter 表现力，请在方案中说明建议技术栈（customtkinter / pywebview+HTML / Tauri 等）与迁移成本；设计稿本身请框架无关。
- 交付物：1) 高保真主界面（结果态）+ 空态/扫描态/删除确认弹窗；2) 组件与标注（颜色/字号/间距/各状态）；3) 交互说明（筛选、勾选、详情、删除全流程）；4) 图标建议。
- 全中文界面：按钮与标签文案请在设计稿中直接给出。

## 9. 禁止事项

- 不出现任何"永久删除"入口或措辞。
- 高风险项不得呈现为可勾选状态。
- 不引入登录、云服务或任何联网功能。
